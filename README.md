# Resume Analyser and Career Guidance

LLM-based web application that analyses resumes and provides 
career guidance using Flask and Hugging Face.

## Tech Stack
Python, Flask, SQLite, TF-IDF, Scikit-learn, Hugging Face LLM, pdfplumber

## Features
- Upload PDF/DOCX resume and get detailed feedback
- ATS score and format analysis
- Job description matching using TF-IDF
- Career guidance chat
- User authentication with session management

## How to Run
pip install -r requirements.txt
Add your HF_API_KEY in .env file
python app.py
